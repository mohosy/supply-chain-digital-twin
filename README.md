# Supply Chain Digital Twin

A browser-based operations simulator that models material flow between factories, distribution hubs, and retail endpoints.

## Highlights
- Interactive digital twin with shipment animations.
- Demand, risk, and dispatch-rate controls.
- Demand-shock and rerouting actions for scenario stress testing.
- Live KPI monitoring: throughput, delay, stockouts, and service level.

## Stack
- HTML5 Canvas
- Vanilla JavaScript simulation logic
- Responsive CSS dashboard

## Run
Open `index.html` in a modern browser.
